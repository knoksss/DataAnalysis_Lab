## Задача

Извлечь разметку объектов из видео `output.mp4` (кадры с нарисованными bbox) и сохранить в формате **COCO**. Оригинал без рамок - `input.mp4`. Оценить качество извлечения (в т.ч. **IoU**), обучить детектор (**Faster R-CNN**), посчитать **mAP** и собрать видео с **собственной** разметкой через **OpenCV**.

| Файл | Роль |
|------|------|
| `input.mp4` | Видео без bbox |
| `output.mp4` | Видео с визуальной разметкой (для вычитания) |

## Пайплайн

1. Декодирование `input.mp4` и `output.mp4` в последовательность кадров (301 кадр, 1920×1080, 30 FPS).
2. **Извлечение bbox** - вычитание кадров + контуры OpenCV; сравнение с **YOLOv8n**.
3. Экспорт в **COCO** (`annotations.json`) и папку `images/`.
4. **IoU** извлечённой разметки vs YOLO.
5. Дообучение **Faster R-CNN** (`fasterrcnn_resnet50_fpn`), контроль loss train/val.
6. **mAP** на валидации (`torchmetrics`).
7. Визуализация и запись **`extracted_annotations.mp4`**.


## Извлечение разметки

### Метод 1 - вычитание кадров (основной)

```text
absdiff(output, input) → grayscale → threshold(10) → findContours → boundingRect
фильтр: w * h > 20
```

На первом кадре - **8 bbox** (все автомобили на сцене).

### Метод 2 - YOLOv8n (сравнение)

Публичный API: `ultralytics`, модель `yolov8n.pt`, класс **car** (id `2`).

| | Вычитание кадров | YOLOv8 |
|---|------------------|--------|
| Сильные стороны | Все машины на кадре, нет FP на люк | Не нужен `output.mp4` |
| Слабые стороны | Рамка с тенью, чувствительность к свету/камере | Пропуски, люк как машина, другая геометрия bbox |

**Средний IoU** (контуры vs YOLO): **0.454**.

## COCO

- Класс: `car` (category id: 1)
- **301** изображений, **2946** аннотаций (~9.8 bbox на кадр)
- Bbox: `[x, y, width, height]`

## Ограничения

- **Absdiff:** статичная камера, освещение, кузов + тень в одном bbox.
- **YOLO:** дальний ракурс, текстуры (ложные объекты), нужно дообучение под сцену.
