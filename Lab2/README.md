# Лабораторная работа №2. Временные ряды.
## Выполнила: Китаева Дарья. М8О-102БВ-25

## Описание
В рамках лабораторной работы был разработан пайплайн для прогнозирования температуры на неделю вперёд на основе временных рядов погодных данных. Исходные данные представляли собой Excel-файл с ручным вводом, содержащий ошибки, пропуски, выбросы и битую кодировку.
**Задача:** очистить данные, провести анализ временного ряда, построить модели машинного обучения и оценить качество прогноза.

## Структура проекта

```
├── have_fun.xlsx     # Исходные данные

├── README.md         # Описание работы

```

## Этапы работы

### 1. Загрузка и очистка данных
- Получен доступ ко всем листам Excel, включая скрытые;
- Обнаружены и удалены пустые листы;
- Исправлена битая кодировка названий городов;
- Текстовые значения в числовых колонках заменены на NaN и интерполированы;
- Удалены выбросы, температура выше +45°C и ниже -45°C.

### 2. Анализ временного ряда
- **График температуры:** видна годовая сезонность;
- **ADF-тест:** доказано, что ряд стационарный;
- **Декомпозиция:** выделены тренд, сезонность и остатки;

### 3. Создание признаков
- Лаги температуры;
- Скользящее среднее за 7 дней;
- Временные признаки: день года, месяц, день недели;
- One-hot кодирование городов.

### 4. Моделирование
Обучены три модели с хронологическим разделением (train < 2024, val = 2024, test = 2025):
- Дерево решений: 3.26
- Случайный лес: 2.84
- XGBoost: 2.8

### 5. Оптимизация гиперпараметров
Лучшие параметры XGBoost:
- `n_estimators = 248`
- `max_depth = 3`
- `learning_rate = 0.098`
- `subsample = 0.767`

MAE на валидации улучшен до **2.75**

## Результаты

- **Лучшая модель:** XGBoost с подбором гиперпараметров
- **MAE на тесте:** 3.00
- **Итог:** модель способна предсказывать температуру на неделю вперёд с ошибкой около 3 градусов, что является хорошим результатом для погодных данных
